# Примеры тест-кейсов администратора (SCORM)

**Проект:** Адаптационный курс для сотрудников ритуальной компании  
**Версия:** 1.1  
**Дата:** июнь 2026  
**Окружение:** Windows 10/11, Chrome/Edge, Frontend :8000, Backend :5000  
**Администратор:** `iereevamaria` / `mariamegaadministrator`

К каждому тесту прилагается **подтверждающий скриншот** (см. [инструкцию](Инструкция_подтверждающие_скриншоты_тестирования.md)).

## TC-ADM-SCORM-N001 — негативный

<table>
  <tr>
    <th>Id теста</th>
    <th>Название теста</th>
    <th>Краткое описание теста</th>
  </tr>
  <tr>
    <td>TC-ADM-SCORM-N001</td>
    <td>SCORM 1.2 не поддерживается runtime</td>
    <td>Администратор загружает пакет SCORM 1.2. LMS определяет версию, но плеер использует только API SCORM 2004 — прогресс не сохраняется. Тип: N. Приоритет: P1.</td>
  </tr>
  <tr>
    <th>Этапы теста</th>
    <th>Ожидаемый результат</th>
    <th>Фактический результат</th>
    <th>Статус</th>
  </tr>
  <tr>
    <td>
      1. Войти как администратор<br>
      2. Загрузить ZIP-пакет SCORM 1.2<br>
      3. Назначить курс обучающемуся (экспертом) и открыть его<br>
      4. Открыть консоль браузера (F12) на странице курса
    </td>
    <td>
      Импорт SCORM 1.2 отклонён <strong>или</strong> при запуске отображается явное предупреждение; прогресс записывается в БД
    </td>
    <td>
      Курс принят в каталог (<code>version: "1.2"</code> в метаданных), но при запуске контент вызывает <code>API.LMSInitialize()</code> (SCORM 1.2) — в консоли ошибка, файл <code>scorm_state</code> не создаётся, прогресс в БД отсутствует.
    </td>
    <td>Завершилось ошибкой</td>
  </tr>
  <tr>
    <th colspan="4">Подтверждающий скриншот</th>
  </tr>
  <tr>
    <td colspan="4">
      <strong>Файл:</strong> <code>docs/testing_screenshots/TC-ADM-SCORM-N001.png</code><br>
      <strong>Что должно быть видно:</strong> консоль браузера (F12) с ошибкой вида <code>API is undefined</code> / <code>LMSInitialize is not a function</code> на фоне открытого SCORM-курса; либо пустой каталог <code>uploads/scorm_state/</code> для данного назначения.<br>
      <em>Скриншот подтверждает выявленный дефект совместимости версий SCORM.</em>
    </td>
  </tr>
</table>
