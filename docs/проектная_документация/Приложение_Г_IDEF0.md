### Расшифровка ICOM

| Тип | Код | Элемент | Описание |
|-----|-----|---------|----------|
| **Вход** | I1 | Учётные данные | Таблицы Users, Position, Roles |
| **Вход** | I2 | Учебные материалы | Файлы в `backend/courses/` |
| **Вход** | I3 | Заявки на назначение | Действия эксперта в assignments.html |
| **Управление** | C1 | Политика обучения | Сроки date_from–date_to, обязательность курса |
| **Управление** | C2 | ТЗ | Приложение Б |
| **Управление** | C3 | Порог 70% | `PASS_THRESHOLD` в course_progress.py |
| **Управление** | C4 | Роли | PAGE_ACCESS, JWT role |
| **Механизм** | M1 | LMS | Программная платформа |
| **Механизм** | M2–M4 | Пользователи | Эксперт, админ, обучающийся |
| **Выход** | O1 | Рейтинг | GET /api/rating |
| **Выход** | O2 | Отчёты | course_report.xlsx |
| **Выход** | O3 | Результаты | Assignments, Section_progress, User_result |

### Описание подфункций A1–A4

| ID | Название | Вход | Выход | Управление | Механизм | Реализация |
|----|----------|------|-------|------------|----------|------------|
| **A1** | Аутентификация и пользователи | I1 | JWT, Users | C4 | M1, M3 | login.html, users.html, POST /api/login |
| **A2** | Каталог курсов | I2 | Courses | C2 | M1, M3 | admin-courses.html, scorm_importer |
| **A3** | Назначение и прохождение | I3, данные A1, A2 | Section_progress | C1, C4 | M2, M4 | assignments.html, course-app.js |
| **A4** | Учёт и отчётность | данные A3 | O1, O2, O3 | C3 | M1, M2 | rating.html, get_report_data() |

### Потоки между подфункциями

1. **A1 → A3:** только авторизованный пользователь с ролью student/expert и активным назначением открывает курс.
2. **A2 → A3:** при назначении и запуске используется `Courses.storage` и manifest.
3. **A3 → A4:** каждое `completeSection` и `finishCourse` обновляет БД для аналитики.
