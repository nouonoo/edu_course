# Глава 5. Аппаратные и программные средства для функционирования

Для правильной работы АИС «Адаптационный курс для сотрудников ритуальной компании» (платформа электронного обучения LMS) необходимо наличие на рабочих местах пользователей и сервера следующего программного обеспечения и аппаратных ресурсов.

---

## Программное обеспечение

- **Операционная система** Microsoft Windows 10 или Windows 11 (64-bit);
- **Python 3.10+** — интерпретатор с поддержкой venv (на Windows рекомендуется команда `py -3`);
- **Microsoft SQL Server** (Express, Developer или LocalDB) — сервер СУБД;
- **ODBC Driver 17 for SQL Server** — драйвер подключения backend к базе данных;
- **SQL Server Management Studio (SSMS)** — для выполнения скрипта `LearningPlatformDB.sql` (рекомендуется);
- **Веб-браузер** Google Chrome, Microsoft Edge или Mozilla Firefox (актуальная версия) — для работы с интерфейсом LMS и курсом-плеером;
- **Microsoft Excel** или совместимое ПО — для просмотра отчётов `course_report.xlsx` (роли эксперт и администратор);
- **Visual Studio Code / Cursor** — для разработки и сопровождения (не обязательно на рабочем месте обучающегося);
- **WinRAR** (опционально) — только на сервере backend для функции «Скачать RAR»; при отсутствии используется ZIP.

## Порядок проверки работоспособности

Для проверки работоспособности информационной системы на рабочем месте пользователя необходимо выполнить следующие действия:

1. Убедиться, что SQL Server запущен и база `LearningPlatformDB` создана скриптом `LearningPlatformDB.sql` (или обновлена через `migration.sql`).
2. Запустить backend: в каталоге `backend` выполнить `py -3 app.py` (порт **5000**).
3. Запустить frontend: в каталоге `frontend` выполнить `py -3 -m http.server 8000`.
4. Открыть в браузере адрес http://127.0.0.1:8000/login.html.
5. Ввести выданные учётные данные (см. таблицу тестовых учётных записей ниже).
6. Нажать кнопку **«Войти»**.
7. Убедиться, что открылась стартовая страница, соответствующая роли пользователя, и данные загружаются без сообщения «Ошибка загрузки».

Дополнительная проверка: выполнить smoke-тесты TC-AUTH-001 и TC-COURSE-001 (см. [Глава 4](Глава_4_Тестирование_и_проверка_работоспособности.md)).

# Инструкции пользователя и администратора системы

Основная цель руководства пользователя заключается в обеспечении пользователя необходимой информацией для самостоятельной работы с программой или автоматизированной системой.

Руководство администратора адресовано лицу, задача которого — обеспечить определённый порядок функционирования системы. Администратор считается пользователем системы, однако наделён особыми обязанностями и привилегиями по управлению учётными записями и каталогом курсов.

Ниже представлена инструкция, адаптированная для LMS ритуальной компании. Расширенная версия с иллюстрациями — в [Руководство пользователя](Руководство_пользователя.md).

## 1. Введение

### 1.1. Область применения

Требования настоящего документа применяются при:

- предварительных комплексных испытаниях;
- опытной эксплуатации;
- приёмочных испытаниях;
- промышленной эксплуатации платформы электронного обучения.

### 1.2. Краткое описание возможностей

Информационная система «Адаптационный курс для сотрудников ритуальной компании» предназначена для:

- прохождения адаптационных электронных и SCORM-курсов (в том числе курса «Правила использования ИТ-ресурсов» / «Безопасность»);
- назначения обучения сотрудникам экспертами (руководителями, наставниками);
- ведения рейтинга успеваемости и формирования отчётов Excel;
- администрирования учётных записей и каталога курсов.

### 1.3. Уровень подготовки пользователя

Пользователь информационной системы должен иметь опыт работы с ОС Windows, навык работы с веб-браузером, а также обладать следующими знаниями:

- знать соответствующую предметную область (адаптация сотрудников ритуальной компании);
- понимать назначение своей роли (обучающийся, эксперт или администратор).

Умения пользователя должны позволять:

- авторизоваться в системе по логину и паролю;
- выполнять операции, соответствующие роли (прохождение курса, назначение обучения, управление пользователями).

### 1.4. Назначение и условия применения

ИС предназначена для автоматизации адаптационного обучения сотрудников организации. Работа с системой возможна в период назначенного обучения (поля `date_from` — `date_to` в таблице `Assignments`). Доступ имеют пользователи с активной учётной записью (`status = active`) и корректными учётными данными.

**Адрес входа:** http://127.0.0.1:8000/login.html

### 3.1. Обучающийся — прохождение курса «Безопасность»

1. Войти под учётной записью обучающегося.
2. На «Моё обучение» выбрать курс в списке.
3. Нажать **«НАЧАТЬ КУРС | →»** — курс откроется на порту 5000.
4. Пройти экраны: обложка → инструкция → введение → **разделы 1–6** (оцениваемые) → заключение.
5. На каждом экране выполнить все интерактивы; кнопка **«Далее»** активируется после их завершения.
6. Для успешного завершения набрать **не менее 70 %** суммарного балла.
7. При необходимости прервать обучение — **«Закрыть курс»** (прогресс сохраняется для завершённых разделов).

### 3.2. Эксперт — назначение курса

1. Войти под учётной записью эксперта.
2. Открыть **«Назначения»**, на карточке курса нажать **«Назначить курс»**.
3. Выбрать сотрудника, указать даты начала и окончания обучения.
4. Нажать **«Назначить →»**. При дублировании активного назначения система вернёт ошибку.

### 3.3. Администратор — управление пользователями и курсами

**Пользователи:** кнопка **«добавить»** → заполнить ФИО, логин, пароль, роль, должность, статус → **«Сохранить»**. Поиск по ФИО — поле «Поиск».

**Курсы:** страница **«Курсы»** → **«Загрузить курс»** (ZIP с `imsmanifest.xml` или `course.json`) → **«Действия»** (редактировать, скачать, удалить).

| Работа с данными в базе SQL Server | Хранение учётных записей сотрудников | CRUD операции над таблицей `Users` (роль администратора) |
| | Каталог курсов | Таблица `Courses`, файлы в `backend/courses/` |
| | Назначения обучения | Таблица `Assignments`: связь сотрудник — курс — период — статус |
| | Прогресс и результаты | `Section_progress` (пошаговый прогресс), `User_result` (итоговый балл) |
| Электронное обучение | Прохождение нативного курса | Gating-навигация, квизы, сохранение через REST API (`lms-bridge.js`) |
| | Поддержка SCORM 2004 | Импорт ZIP, runtime API, синхронизация прогресса |
| Формирование отчётности | Рейтинг сотрудников | Страница `rating.html`, агрегация баллов по курсам |
| | Excel-отчёт | `GET /api/report` → файл `course_report.xlsx` |

# Заключение

В ходе выполнения курсовой работы была достигнута основная цель — разработано программное обеспечение АИС «Адаптационный курс для сотрудников ритуальной компании»: платформа электронного обучения для адаптации персонала ритуальной организации.

В теоретической части был проведён анализ предметной области, сравнение аналогов, составлен план работ и определён жизненный цикл создания проекта (проектная документация, приложения А–И).

В практической части:

- построены диаграммы (IDEF0, Use Case, ER, последовательностей) и создана база данных **LearningPlatformDB** из восьми используемых таблиц;
- реализована физическая модель и программная часть: backend на **Flask** (порт 5000), frontend на **HTML/JS/CSS** (порт 8000), интеграция с **SQL Server** через **ODBC**;
- разработан нативный адаптационный курс **«Безопасность»** (`bezopasnost`) с gating-навигацией, интерактивами и сохранением прогресса в **Section_progress**;
- обеспечена поддержка **SCORM 2004**, рейтинга и **Excel-отчётов**;
- организована безопасность АИС: JWT-авторизация, хеширование паролей, разграничение прав по ролям (администратор, эксперт, обучающийся);
- проведено тестирование по **28 тест-кейсам** (TC-AUTH, TC-ASGN, TC-COURSE, TC-RATE, TC-ADM, TC-UI, TC-PROF, TC-UNIT) и автоматизированным юнит-тестам `test_course_progress.py`;
- определены аппаратные и программные требования для функционирования системы и подготовлены инструкции для пользователей всех ролей.

По завершении курсовой работы программное обеспечение LMS готово к опытной эксплуатации в учебной и организационной среде заказчика. Дальнейшее развитие системы может включать развёртывание на HTTPS, резервное копирование БД, расширение каталога адаптационных курсов и интеграцию с кадровой системой предприятия.
