# Инструкция: как сделать подтверждающие скриншоты для тест-кейсов

Документ для самостоятельного оформления раздела тестирования в пояснительной записке и дипломной презентации.

---

## 1. Зачем нужны скриншоты

Тест-кейс описывает шаги и ожидаемый результат. **Подтверждающий скриншот** — это доказательство, что тест реально выполнялся: на картинке виден интерфейс LMS в момент проверки (успех или ошибка).

Примеры тест-кейсов со скриншотами: [Тест-кейсы_администратор_примеры.md](Тест-кейсы_администратор_примеры.md).

---

## 2. Подготовка окружения

1. Запустите SQL Server и убедитесь, что база `LearningPlatformDB` создана.
2. В каталоге `backend` выполните:
   ```bash
   py -3 app.py
   ```
3. В каталоге `frontend` выполните:
   ```bash
   py -3 -m http.server 8000
   ```
4. Откройте браузер: http://127.0.0.1:8000/login.html

---

## 3. Куда сохранять файлы

Создайте папку (если её ещё нет):

```
docs/testing_screenshots/
```

Имена файлов — **как в тест-кейсе**:

| Тест | Имя файла |
|------|-----------|
| TC-ADM-SCORM-P001 | `TC-ADM-SCORM-P001.png` |
| TC-ADM-SCORM-N001 | `TC-ADM-SCORM-N001.png` |

Для других тестов из [Тест-кейсы.md](Тест-кейсы.md) используйте тот же принцип: `TC-AUTH-001.png`, `TC-ASGN-001.png` и т.д.

## 4. Как сделать скриншот в Windows

### Способ 1 — «Ножницы» / Win+Shift+S (рекомендуется)

1. Выполните шаги теста до нужного экрана.
2. Нажмите **Win + Shift + S**.
3. Выделите область: весь браузер или нужный фрагмент (список курсов, сообщение об ошибке).
4. Скриншот попадёт в буфер обмена → вставьте в Paint → **Сохранить как** → PNG в `docs/testing_screenshots/`.

### Способ 2 — через браузер

1. Откройте DevTools: **F12**.
2. Для негативного теста SCORM 1.2: вкладка **Console** должна быть видна на скриншоте вместе с окном курса.
3. **Ctrl + Shift + P** → введите `screenshot` → выберите **Capture full size screenshot** (Chrome/Edge).

## 5. Что снимать для примеров из проекта

### TC-ADM-SCORM-P001 (позитивный)

**Шаги:**
1. Войти: `iereevamaria` / `mariamegaadministrator`.
2. Открыть **Курсы**.
3. Загрузить ZIP SCORM 2004 (например, экспорт Articulate Rise / iSpring).
4. Сделать скриншот, когда курс появился в списке.

**На скриншоте должно быть видно:** название нового курса в таблице, страница `admin-courses.html`, при возможности — зелёное/информационное сообщение «Курс загружен».

**Дополнительно (по желанию):** второй скриншот — содержимое `backend/courses/<папка>/scorm_meta.json` с строкой `"version": "2004"`.

### TC-ADM-SCORM-N001 (негативный)

**Шаги:**
1. Загрузить пакет **SCORM 1.2** (в манифесте `<schemaversion>1.2</schemaversion>`).
2. Попросить эксперта назначить курс обучающемуся (`miereeva@yandex.ru` → `assignments.html`).
3. Войти как обучающийся (`pkabkov@ra.ru` / `petya`), открыть курс.
4. Нажать **F12** → вкладка **Console**.
5. Сделать скриншот: слева — курс в iframe, справа или снизу — ошибка в консоли.

**На скриншоте должно быть видно:** текст ошибки про отсутствие `API` / `LMSInitialize` — это подтверждает, что runtime SCORM 2004 не совместим с пакетом 1.2.

## 6. Как вставить скриншот в пояснительную записку (Word)

1. Откройте DOCX главы 4 или приложение с тест-кейсами.
2. После таблицы теста вставьте рисунок: **Вставка → Рисунки**.
3. Подпись по ГОСТ, например:  
   **Рисунок 27 – Результат теста TC-ADM-SCORM-P001 (успешная загрузка SCORM 2004)**
4. В тексте главы 4 добавьте ссылку: «подтверждено рисунком 27».

### Вставка в Markdown (для репозитория)

В файл `Тест-кейсы_администратор_примеры.md` можно добавить:

```markdown
![TC-ADM-SCORM-P001](testing_screenshots/TC-ADM-SCORM-P001.png)
*Рисунок – успешная загрузка SCORM 2004*
```

## 7. Чек-лист перед сдачей

- [ ] Оба файла лежат в `docs/testing_screenshots/`
- [ ] Имена совпадают с Id теста
- [ ] На скриншоте читаемый текст (масштаб браузера 100 %)
- [ ] Не видно лишних личных данных (при необходимости закройте лишние вкладки)
- [ ] В Word/PDF рисунки подписаны и упомянуты в главе 4

## 8. Расширение на другие тесты

Тот же порядок подходит для любого тест-кейса из [Тест-кейсы.md](Тест-кейсы.md):

| Модуль | Что снимать |
|--------|-------------|
| Авторизация | Страница после входа или сообщение об ошибке на `login.html` |
| Назначения | Модальное окно назначения + подтверждение |
| Курс | Экран курса с прогресс-баром |
| Рейтинг | Таблица рейтинга или скачанный `course_report.xlsx` в Excel |
| Админ | Список пользователей / каталог курсов |

Полный комплект скриншотов усиливает раздел «Тестирование» на защите диплома.
